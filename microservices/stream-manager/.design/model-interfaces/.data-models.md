# Data Models

## Recording Data Models

### Recording
| Field | Type | Description |
|-------|------|-------------|
| recording_id | string | Unique identifier for the recording |
| sensor_id | string | Identifier for the sensor that captured the recording |
| stream_id | string | Identifier for the stream associated with the recording |
| start_ts | time.Time | Start timestamp of the recording |
| end_ts | time.Time | End timestamp of the recording |
| recording_path | string | Path to the recorded media file |
| codec | string | Codec used for the recording (e.g., "H.264", "VP8") |
| state | string | Current state of the recording; One of these - "recording", "finalizing", "ready", "failed" |
| size_bytes | int64 | Size of the recorded media file in bytes |
| metadata | map[string]interface{} | Additional metadata associated with the recording |
| error_detail | string | Details of any error encountered during the recording |
| creation_ts | time.Time | Timestamp when the recording was created |
| expiry_ts | time.Time | Timestamp when the recording is set to expire |

### recordingResponse
| Field | Type | Description |
|-------|------|-------------|
| recording_id | string | Unique identifier for the recording |
| sensor_id | string | Identifier for the sensor that captured the recording |
| stream_id | string | Identifier for the stream associated with the recording |
| start_ts | time.Time | Start timestamp of the recording |
| end_ts | time.Time | End timestamp of the recording |
| state | string |  One of these - "recording", "finalizing", "ready", "failed" |
| size_bytes | int64 | Size of the recorded media file in bytes |
| metadata | map[string]interface{} | Additional metadata associated with the recording |
| creation_ts | time.Time | Timestamp when the recording was created |
| expiry_ts | time.Time | Timestamp when the recording is set to expire |
| error_detail | string | Details of any error encountered while getting the recording |

### RecordingFilter
| Field | Type | Description |
|-------|------|-------------|
| sensor_id | string | Filter by sensor ID |
| stream_id | string | Filter by stream ID |
| start_ts | time.Time | Filter by start timestamp (e.g., recordings starting after this time) |
| end_ts | time.Time | Filter by end timestamp (e.g., recordings ending before this time) |
| expiry_ts | time.Time | Filter by expiry timestamp (e.g., recordings set to expire before this time) |
| state | string | Filter by recording state - "recording", "finalizing", "ready", "failed" |
| metadata | map[string]interface{} | Filter by additional metadata associated with the recording |
| cursor | string | Cursor for pagination |
| limit | int | Maximum number of records to return |


## Stream Buffer Data Models

### StreamBuffer
| Field | Type | Description |
|-------|------|-------------|
| stream_id | string | Identifier for the stream associated with the buffer |
| sensor_id | string | Identifier for the sensor associated with the buffer |
| state | string | Current state of the buffer - "connecting", "buffering", "reconnecting", "failed" |
| sync_confidence | string | Confidence level of the buffer synchronization |
| slices | []BufferSlice | List of buffer slices contained within the buffer |
| bufferStat.held_bytes | int64 | Number of bytes currently held in the buffer |
| bufferStat.capacity | int | Total capacity of the buffer in seconds |
| bufferStat.oldest_ts | time.Time | Timestamp of the oldest data in the buffer |
| bufferStat.newest_ts | time.Time | Timestamp of the newest data in the buffer |
| frameStat.framerate | float64 | Frame rate of the buffer |
| frameStat.dropped_frames | int64 | Number of frames dropped in the buffer |
| creation_ts | time.Time | Timestamp when the buffer was created |

### BufferSlice
| Field | Type | Description |
|-------|------|-------------|
| seq_no | int | Sequence number of the buffer slice |
| start_ts | time.Time | Start timestamp of the buffer slice |
| end_ts | time.Time | End timestamp of the buffer slice |
| path  | string | tempfs path to the buffer slice |
| pts_start | int | Media presentation timestamp (PTS) of the start of the buffer slice |
| pts_end | int | Media presentation timestamp (PTS) of the end of the buffer slice |
| size_bytes | int64 | Size of the buffer slice in bytes |
| keyframe_ts | time.Time | Timestamp of the first keyframe within the buffer slice |
| ref_count | int | Number of active readers (leases) currently holding this slice open |

### bufferStat
| Field | Type | Description |
|-------|------|-------------|
| held_bytes | int64 | Number of bytes currently held in the buffer |
| capacity | int | Total capacity of the buffer in seconds |
| oldest_ts | time.Time | Timestamp of the oldest data in the buffer |
| newest_ts | time.Time | Timestamp of the newest data in the buffer |

### frameStat
| Field | Type | Description |
|-------|------|-------------|
| framerate | float64 | Frame rate of the buffer |
| dropped_frames | int64 | Number of frames dropped in the buffer |

## Replay Data Models

### MediaResult
| Field | Type | Description |
|-------|------|-------------|
| recording_id | string | Identifier for the associated recording |
| sensor_id | string | Identifier for the sensor that captured the media result |
| media_type | string | Type of the media result (e.g., "clip", "frame") |
| content_type | string | MIME type of the media content for the result |
| requested_start_ts | time.Time | Requested start timestamp for the media result (e.g., for a clip) |
| requested_end_ts | time.Time | Requested end timestamp for the media result (e.g., for a clip) |
| start_ts | time.Time | Start timestamp of the media result |
| end_ts | time.Time | End timestamp of the media result |
| url | string | URL to access the clip or frame |
| expiry_ts | time.Time | Expiry timestamp of the media |
